# 🏠 Property-Rent-Management-System

**Property Rent Management System** is a flat-rental platform designed to help users discover flats in their desired location. Sellers can register, log in, add flat details, and manage their listed properties through a dedicated dashboard.

> **Created by Priyanshu**

---

## 📌 Overview

Property Rent Management System provides a simple platform for discovering and managing rental flats.

Users can browse available flats and search/filter properties based on information such as **BHK, location, and description**.

Sellers have additional functionality to:

* Register an account
* Log in to their account
* Add new flats
* Manage their listed flats
* View flat availability
* Provide rental and contact information

---

## ✨ Features

### 👤 For Users

* Browse available flats
* View flat details
* Search flats
* Filter flats by:

  * BHK
  * Location
  * Description

### 🏢 For Sellers

* Seller registration
* Seller login

## 🔄 How It Works

### Step 1 — Seller Registration

Sellers create a new account by providing:

* Username
* Email
* Password

After registration, the seller can proceed with the required ID process.

### Step 2 — Seller Login

Registered sellers can log in using their:

* Username
* Password

### Step 3 — Add a Flat

Sellers can add a new property by providing:

* Flat name
* Full address
* Owner contact number
* Area
* Description
* Rent price
* Availability

### Step 4 — Manage Flats

Added properties appear in the **My Flats** dashboard, where sellers can review their listed properties and their current status.

### Step 5 — Contact & Support

Users can contact the platform for questions, reporting issues, or technical support.
